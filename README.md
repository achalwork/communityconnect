# Community Connect (frontend prototype)

```
npm install
npm run dev
```

All data is mock. OTP, payments and GPS check-in are simulated. Role guards are demo only; real authorization, payment verification (e.g. Razorpay) and GPS validation must be enforced by the backend.

Structure: `src/App.jsx` holds all screens and mock data. Next step is splitting it into components/, pages/, services/ and data/ for the Spring Boot API.
